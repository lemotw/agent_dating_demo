# 操作與人工驗收指南

以下為建議驗收步驟，並非已完成的自動化測試報告。

## 快速操作

1. 開啟 `index.html`，輸入虛構暱稱，勾選原型與成人聲明。
2. 每題可點「填入示範回答」後送出，或跳過。共六個訪談方向。
3. 在摘要頁編輯文字並勾選允許分享的項目；至少分享一項才能進入探索。
4. 對第一位「林安」右滑或按喜歡，觸發示範雙向配對。
5. 確認授權預覽，勾選同意後啟動 Agent 交流。
6. 等待六則示範訊息，或測試暫停／繼續，再開啟報告。
7. 選擇是否繼續；若邀請聊天，點「模擬對方也同意」進入真人聊天示範。
8. 送出本機訊息。系統不會假裝有真人回覆。

## 分支驗收清單

- [ ] 空白暱稱或未確認必要聲明時，不能開始。
- [ ] 訪談可以跳過，空白回答不會被誤當成已提供背景。
- [ ] 所有分享勾選預設關閉，第 4 題個人故事不預填到分享摘要。
- [ ] 勾選但摘要空白時不納入授權內容；零有效摘要不能繼續。
- [ ] 修改摘要後，配對確認頁顯示最新選擇。
- [ ] 左滑不會觸發配對。
- [ ] 第二位人物右滑只顯示等待，不啟動 Agent。
- [ ] 第一與第三位人物右滑會觸發示範雙向配對。
- [ ] 未勾選本次交流授權時不能啟動。
- [ ] 暫停後不再出現新交流訊息，繼續後恢復。
- [ ] 中途結束清除計時器，不繼續產生示範訊息。
- [ ] 報告對未授權欄位標示未提供，不自行補完。
- [ ] 報告沒有相容度百分比或真人事實保證。
- [ ] 單方邀請不直接打開真人聊天。
- [ ] 選擇不繼續時不開啟聊天。
- [ ] 看完卡片後顯示結束狀態，可重新瀏覽。
- [ ] 清除或重新整理後，暱稱、回答與對話狀態重置。
- [ ] 手機可用滑動及按鈕操作；鍵盤可操作表單與按鈕。

## 前版原型

`agent-lounge.html` 可測試主題搜尋、可加入篩選、滿員禁用、自訂開房、模擬加入、輪流聊天、暫停／繼續與重播。這是 Dating 方向之前的概念保存，不代表目前的主產品流程。
